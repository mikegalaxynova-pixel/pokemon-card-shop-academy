# 宝可梦卡牌店 · 开店学堂

给零基础、打算在日本开宝可梦卡牌店的人的一套完整学习系统。
先学懂宝可梦和卡，再懂市场，再学开店，最后学运营和推广——按顺序学，不用每天追新闻。

- 读者：中文读者（附日文术语和英文名），人在日本或准备来日本开店
- 形式：GitHub Pages + Jekyll 静态站，手机优先，推送即发布，无需本地构建
- 维护节奏：每周一次「资讯与价格观察」，其余时间只按学习路径补内容。不日更。

## 和旧站（pokemon-card-shop-course）的区别

| | 旧站 | 本站 |
|---|---|---|
| 组织方式 | 以每日新闻为中心 | 以学习路径为中心，新闻是辅助 |
| 宝可梦介绍 | 不写 | 独立模块：先懂宝可梦，才懂卡为什么值钱 |
| 玩法 | 不写 | 写基础玩法：店员必须能陪客人聊、能办活动 |
| 内容范围 | 只写 PSA 评级卡 | 评级卡 + 生卡 + 新品 + 周边，全店型视角 |
| 店型 | 默认东京 PSA 小店 | 先选店型（综合卡店 / 评级卡专门 / 买取中心 等）再学对应内容 |
| 工具 | 只有收支平衡计算器 | 计算器 ×2 + 开店清单 + 每日清单 + 真伪检查表 + 模板 |
| 推广 | 排在路线图最后 | 独立模块，和运营同等优先级 |
| 更新负担 | 每天 20:00 日更 | 每周一更，可持续 |

## 仓库结构

- `*.md`（根目录）：各模块页面，front matter 里有 `layout: lesson`、`module`、`order`、`level`
- `_data/modules.yml`：模块和学习路径的唯一数据源
- `_layouts/`、`_includes/`：自写轻量布局，内联关键 CSS，其余在 `assets/`
- `assets/js/main.js`：搜索、清单进度（localStorage）、两个计算器
- `CONTRIBUTING.md`：怎么写新内容（短版，故意保持简单）
- `ROADMAP.md`：接下来按需做什么

## 原则

1. 事实必须有来源；价格、租金、法规以官方和主管机关最新信息为准，算例一律标明是假设。
2. 不写站长个人的开店地点、货源和进度，例子用通用情形。
3. 每篇开头先给结论和「学完你能做什么」，再展开。
4. 内容为学习整理，不构成法律、税务或投资建议。
